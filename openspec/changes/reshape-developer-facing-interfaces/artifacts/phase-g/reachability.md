## Behavioral probe

In a disposable checkout, a throwing sentinel checked the zero-instruction dispatch in `Interpreter.RunAsync`, immediately before its existing branch. The Release build passed with warnings as errors. Ephemeral (466), durable (158), Core (408), acceptance (37) and ordinary hosting (126) passed. Reversing that predicate made `SelectedParallel_ExecutesIsolatedBranchesAndMergesInAuthoredOrder` fail at the sentinel. This probes the executed journeys and complements the compiler and constructor trace.

The migration order follows these dependencies. Port missing observable cases against the original engine, then move live Init and End reads to compiled instructions while the old graph is still available. Verify parity at that boundary before deleting the recursive engine, its exclusive helpers and the duplicate runtime tree. Active declaration and recovery ledgers continue to own excluded historical test sources.
