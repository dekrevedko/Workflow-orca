# Ephemeral start-key retirement

Which instance can a same-key caller observe if it pins the old binding while an age sweep and a competing start run? The canonical requirement makes actual retirement the boundary for reuse. A retained compatible replay returns the original instance with `WasExisting = true`. A conflict describes the binding inspected. Once a new owner publishes, a fresh inspection compares against that replacement. [Start idempotency and atomic retirement](../../../openspec/specs/management-and-querying/spec.md#requirement-ephemeral-start-idempotency-expires-with-atomic-retirement)

Extend the existing start protocol with a focused model of one key in an open host, an already published and physically settled instance, two further callers, and one possible replacement generation. Vary fingerprint compatibility. Separate pin and decision under the visibility gate, release of the pin, retirement selection, delayed physical cleanup, replacement reservation/publication, and observation of the saved decision. Age eligibility may arrive before inspection. A sweep while pinned and enforcement on final release must both be reachable.

Check that a pinned binding survives, results identify the generation inspected, old handles retain their identity after retirement, and cleanup selected for the old instance cannot remove a replacement. Check that only one caller creates the replacement and that an incompatible caller observes the bound generation's typed conflict. Exercise both admission orders, including a result observed after another caller reuses the key. Inject faults in pin protection, result binding and delayed cleanup.

Replay deterministic schedules against the facade, lifetime and retention tests. Distinguish a query-held lifetime pin from the short replay pin inside `StartCoreAsync`. Exercise a genuine replay across retirement during its return, and inspect instance IDs, conflict identity, `WasExisting`, ordinary handle access and replacement start count. Leave shutdown, disabled retention, crash recovery, additional generations and external-effect deduplication outside this model. The existing start model covers cancellation and provisional abort.
